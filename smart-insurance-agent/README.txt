Smart Insurance Agent
=====================
A simple rule-based insurance advisor chatbot (Health, Life, Motor).

How to run:
  Double-click index.html to open it in any browser. No installation needed.

How to customise:
  Open index.html in a text editor and edit the config block at the top of
  the <script> section:
    TYPES - plans, base rates, multipliers, perks
    FLOW  - questions and risk-point rules
    FAQ   - keyword answers
    CUR   - currency symbol

Note: Premium figures are illustrative placeholders, not real quotes.
